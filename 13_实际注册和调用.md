中台项目需要数据库，而且这是中台项目从 Demo 走向成品化的关键。  
**中台不是只转发请求的网关，它必须有自己的资产库、权限库、版本库、调用审计库、知识索引元数据库。**

先给结论：

> 真实 Agent 接入中台时，不是把 Agent 的全部代码搬到中台，而是把它内部的“知识库、工具、Skill、Prompt、Agent整体能力”抽象成统一的 `Capability`，通过注册 API / SDK / YAML 配置注册到中台。中台保存元数据、权限、版本、调用方式和审计记录；真正执行时，可以由中台托管，也可以代理调用原 Agent 的接口。

下面用一个完整例子说明。

# 1. 总体注册关系

假设公司已有一个 **运营智能体**，它内部有：

```text
运营智能体 OperationAgent
├── 知识库：门店运营知识库
├── 知识库：直播运营知识库
├── 工具：客户分层分析工具
├── 工具：活动指标计算工具
├── Skill：直播话术生成 Skill
├── Prompt：门店运营诊断 Prompt
└── Agent整体能力：运营方案生成能力
```

接入中台后，不建议让其他 Agent 直接调用运营智能体内部的工具，而是注册到中台：

```text
运营智能体
   ↓ 注册资产
知识库中台 Capability Registry
   ├── kb_store_operation
   ├── kb_live_operation
   ├── tool_customer_segment
   ├── tool_metric_calc
   ├── skill_live_script_generator
   ├── prompt_store_diagnosis
   └── agent_operation
```

之后多 Agent 协作系统中的主控 Agent 或其他子 Agent 只调用中台：

```text
主控Agent / 财务Agent / 商学院Agent
        ↓
中台 SDK
        ↓
能力检索 / 权限过滤 / 能力调用
        ↓
运营知识库 / 运营工具 / 运营Skill / 运营Agent
```

## 3.2 能力注册中心

所有知识库、工具、Skill、Prompt、Agent整体能力，都统一抽象为 `capability`。

表：`capabilities`

```sql

    id UUID PRIMARY KEY,

    status VARCHAR(50) NOT NULL DEFAULT 'draft',
```

`type` 可以是：

```text

```


# 7. 中台侧：注册接口

`app/api/v1/capabilities.py`

```python
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session

from app.core.database import get_db
from app.models.agent import Agent
from app.models.capability import Capability
from app.schemas.capability import CapabilityCreate

router = APIRouter(prefix="/api/v1/capabilities", tags=["capabilities"])


@router.post("")
def create_capability(
    payload: CapabilityCreate,
    db: Session = Depends(get_db),
):
    existing = (
        db.query(Capability)
        .filter(Capability.code == payload.code)
        .first()
    )
    if existing:
        raise HTTPException(status_code=409, detail="Capability code already exists")

    owner_agent_id = None
    if payload.owner_agent_code:
        agent = (
            db.query(Agent)
            .filter(Agent.agent_code == payload.owner_agent_code)
            .first()
        )
        if not agent:
            raise HTTPException(status_code=400, detail="Owner agent not found")
        owner_agent_id = agent.id

    capability = Capability(
        code=payload.code,
        name=payload.name,
        type=payload.type,
        description=payload.description,
        owner_agent_id=owner_agent_id,
        owner_department=payload.owner_department,
        domain=payload.domain,
        tags=payload.tags,
        permission_tags=payload.permission_tags,
        input_schema=payload.input_schema,
        output_schema=payload.output_schema,
        endpoint=payload.endpoint,
        invoke_method=payload.invoke_method,
        execution_mode=payload.execution_mode,
        risk_level=payload.risk_level,
        sensitivity_level=payload.sensitivity_level,
        version=payload.version,
        status=payload.status,
    )

    db.add(capability)
    db.commit()
    db.refresh(capability)

    return {
        "id": str(capability.id),
        "code": capability.code,
        "name": capability.name,
        "type": capability.type,
        "status": capability.status,
        "version": capability.version,
    }
```

# 9. 中台侧：能力调用接口

注册只是第一步。后续其他 Agent 要通过中台调用这个 Skill。

接口设计：

```http
POST /api/v1/capabilities/{capability_code}/invoke
```

`app/api/v1/invoke.py`

```python
from fastapi import APIRouter, Depends, HTTPException
from pydantic import BaseModel
from sqlalchemy.orm import Session

from app.core.database import get_db
from app.models.capability import Capability
from app.services.invoke_service import invoke_capability

router = APIRouter(prefix="/api/v1/capabilities", tags=["invoke"])


class InvokeRequest(BaseModel):
    caller_agent_code: str
    user_id: str | None = None
    task_id: str | None = None
    input: dict


@router.post("/{capability_code}/invoke")
def invoke(
    capability_code: str,
    payload: InvokeRequest,
    db: Session = Depends(get_db),
):
    capability = (
        db.query(Capability)
        .filter(Capability.code == capability_code)
        .first()
    )

    if not capability:
        raise HTTPException(status_code=404, detail="Capability not found")

    if capability.status != "active":
        raise HTTPException(status_code=400, detail="Capability is not active")

    result = invoke_capability(
        db=db,
        capability=capability,
        caller_agent_code=payload.caller_agent_code,
        user_id=payload.user_id,
        task_id=payload.task_id,
        input_data=payload.input,
    )

    return result
```

# 10. 中台侧：代理调用真实 Agent

`app/services/invoke_service.py`

```python
import time
import requests
from fastapi import HTTPException
from jsonschema import validate, ValidationError

from app.models.capability import Capability


def invoke_capability(
    db,
    capability: Capability,
    caller_agent_code: str,
    user_id: str | None,
    task_id: str | None,
    input_data: dict,
):
    started_at = time.time()

    # 1. 参数校验
    if capability.input_schema:
        try:
            validate(instance=input_data, schema=capability.input_schema)
        except ValidationError as e:
            raise HTTPException(
                status_code=422,
                detail=f"Input schema validation failed: {e.message}",
            )

    # 2. 权限校验
    # 这里先简化，实际应该查 capability_permissions
    check_permission(
        caller_agent_code=caller_agent_code,
        capability=capability,
    )

    # 3. 根据执行模式调用
    if capability.execution_mode == "proxy_to_agent":
        response = requests.request(
            method=capability.invoke_method or "POST",
            url=capability.endpoint,
            json=input_data,
            timeout=15,
        )

        if response.status_code >= 400:
            raise HTTPException(
                status_code=502,
                detail={
                    "message": "Downstream agent call failed",
                    "status_code": response.status_code,
                    "body": response.text,
                },
            )

        output = response.json()

    elif capability.execution_mode == "metadata_only":
        raise HTTPException(
            status_code=400,
            detail="Capability is metadata only and cannot be invoked",
        )

    else:
        raise HTTPException(
            status_code=400,
            detail=f"Unsupported execution mode: {capability.execution_mode}",
        )

    # 4. 输出校验
    if capability.output_schema:
        try:
            validate(instance=output, schema=capability.output_schema)
        except ValidationError as e:
            raise HTTPException(
                status_code=502,
                detail=f"Output schema validation failed: {e.message}",
            )

    # 5. 写审计日志
    latency_ms = int((time.time() - started_at) * 1000)

    write_invocation_log(
        db=db,
        capability=capability,
        caller_agent_code=caller_agent_code,
        user_id=user_id,
        task_id=task_id,
        input_data=input_data,
        output_data=output,
        latency_ms=latency_ms,
        status="success",
    )

    return {
        "capability_code": capability.code,
        "capability_name": capability.name,
        "version": capability.version,
        "output": output,
        "latency_ms": latency_ms,
    }


def check_permission(caller_agent_code: str, capability: Capability):
    # 初版可以先简单判断 permission_tags
    # 后面应替换为 RBAC / ABAC 权限服务
    if capability.risk_level == "high" and caller_agent_code not in [
        "finance_agent",
        "master_agent",
    ]:
        raise HTTPException(
            status_code=403,
            detail="Caller agent has no permission to invoke this capability",
        )


def write_invocation_log(
    db,
    capability,
    caller_agent_code,
    user_id,
    task_id,
    input_data,
    output_data,
    latency_ms,
    status,
):
    # 这里可以先打印，后面替换为 InvocationLog ORM
    print(
        {
            "capability": capability.code,
            "caller_agent": caller_agent_code,
            "user_id": user_id,
            "task_id": task_id,
            "latency_ms": latency_ms,
            "status": status,
        }
    )
```

# 14. Tool 注册例子：财务 ROI 工具

财务 Agent 暴露一个工具 API：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(title="Finance Agent")


class ROICalcRequest(BaseModel):
    budget: float
    expected_sales: float
    gross_margin_rate: float


@app.post("/tools/roi-calc")
def roi_calc(payload: ROICalcRequest):
    gross_profit = payload.expected_sales * payload.gross_margin_rate
    roi = gross_profit / payload.budget if payload.budget > 0 else 0

    return {
        "roi": round(roi, 2),
        "gross_profit": round(gross_profit, 2),
        "risk_level": "high" if roi < 1 else "low",
        "suggestion": "ROI低于1，建议降低预算或提升转化目标" if roi < 1 else "预算收益测算基本可行"
    }
```

注册到中台：

```python

    "code": "tool_finance_roi_calc",

    "type": "tool",

    "owner_agent_code": "finance_agent",
    "owner_department": "财务部",
    "domain": "finance",
    "tags": ["budget", "roi", "activity"],
    "permission_tags": ["finance", "budget"],
    "input_schema": {
        "type": "object",
        "properties": {
            "budget": {"type": "number"},
            "expected_sales": {"type": "number"},
            "gross_margin_rate": {"type": "number"}
        },
        "required": ["budget", "expected_sales", "gross_margin_rate"]
    },
    "output_schema": {
        "type": "object",
        "properties": {
            "roi": {"type": "number"},
            "gross_profit": {"type": "number"},
            "risk_level": {"type": "string"},
            "suggestion": {"type": "string"}
        }
```

# 16. 推荐真实接入流程

你们接入真实 Agent 时，不要一上来就迁移所有资产。建议这样做：

```text
第一步：每个 Agent 先注册 Agent 本体
第二步：每个 Agent 选 1 个知识库、1 个工具、1 个 Skill 接入
第三步：中台实现能力检索、调用、权限、审计闭环
第四步：多Agent协作系统通过中台调用这些能力
第五步：逐步治理重复资产，把重复知识库和重复 Skill 合并成公共能力
```

```text
- kb_store_live_operation

- skill_live_script_generator

Prompt：
- prompt_store_operation_diagnosis
```

财务智能体第一批接入：

```text

- finance_agent

- kb_finance_budget_policy
```

# 18. 一句话总结

真实 Agent 接入中台时：

> 每个 Agent 把自己的知识库、工具、Skill、Prompt、整体 Agent 能力，按照统一的 Capability Schema 注册到中台；中台数据库保存能力元数据、输入输出协议、端点、权限、版本、知识索引、调用日志和审计信息；调用时其他 Agent 不直接访问原 Agent，而是通过中台进行能力发现、权限校验、参数校验、代理调用、结果校验和日志追踪。

这样做以后，运营、财务、人事、供应链、商学院等 Agent 就不需要各自维护一堆重复工具，而是都变成：

```text
Agent 专注任务执行
中台负责能力管理、知识治理、权限控制、调用审计和资产复用
```


## 完整架构：

供给侧：Agent Owner / 存量 Agent 服务
  ↓
注册知识库、工具、Skill、Prompt、Agent整体能力
  ↓
中台 Capability Registry + 数据库 + 权限 + 审计

消费侧：主控 Agent / 子 Agent
  ↓
通过 SDK 检索能力
  ↓
通过 SDK 调用能力
  ↓
中台做鉴权、Schema校验、代理调用、审计、返回结果
